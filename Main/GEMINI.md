# Project

This file is the entry point for Gemini-compatible runtimes.

## Read Order

1. Read `CORE.md` as SSOT.
2. Read `RESOLVER.md` to choose one workflow skill.
3. Read only the selected `SKILLS/<skill-name>/SKILL.md`.
4. Load only references, scripts, assets and `KNOWLEDGE/` packs referenced by that selected skill.

## Runtime Notes

- `CLAUDE.md`, `AGENTS.md` ​​and `GEMINI.md` are anchor files only.
- General rules, build/test and work style should not be duplicated here.
- Unknown or unclear tasks route through `RESOLVER.md`.
