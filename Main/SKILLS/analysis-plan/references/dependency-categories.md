# Dependency Categories

| Category | Examples |
|---|---|
| UI | SnapKit, Kingfisher, Lottie, SDWebImage, Snapshot UI helpers |
| Networking | Alamofire, Moya, Apollo, URL routing helpers |
| Storage | Realm, GRDB, SQLite wrappers, Keychain wrappers |
| Testing | Quick, Nimble, SnapshotTesting, ViewInspector, Mocker |
| Utilities | Collections, Algorithms, logging, date/time, JSON helpers |
| Architecture | ComposableArchitecture, RxSwift, Combine helpers, DI frameworks |
| Tooling | SwiftLint, SwiftFormat plugins, code generation tools |

If a package fits several categories, choose the category based on how the project uses it.
