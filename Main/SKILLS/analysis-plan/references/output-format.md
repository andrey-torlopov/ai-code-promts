# Output Format

Default order for analysis deliverables:

1. Scope inspected.
2. Facts.
3. Assumptions.
4. Findings or risks.
5. Recommended plan or decision.
6. Verification strategy.
7. Open questions or blockers.

For code review:

1. Findings first.
2. File and line when available.
3. Why it matters.
4. Specific fix.
5. Verification or test gap.

For saved artifacts, include enough context that another agent can continue without rereading unrelated history.
