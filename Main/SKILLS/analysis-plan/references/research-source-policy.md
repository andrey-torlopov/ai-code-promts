# Source Policy

- Prefer primary sources: official documentation, specifications, repositories, papers, release notes and vendor announcements.
- For latest/current/recent topics, verify with current sources.
- Record source URLs and dates when version or recency matters.
- Distinguish direct facts from inference.
- If sources conflict, show the conflict and explain which source is more authoritative.
- Do not quote long passages. Summarize and cite.
- If browsing or network access is unavailable, state that limitation explicitly.
