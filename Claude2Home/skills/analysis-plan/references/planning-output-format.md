# Planning Output Format

For chat planning:

```text
Task:
Scope:
Confirmed Facts:
Assumptions:
Contradictions / Blockers:
Findings:
Options:
Recommended Plan:
Risks:
Verification Strategy:
Delivery Gate:
Artifacts:
Next Step:
```

For saved Markdown, use:

```markdown
# Analysis Plan

## Task

## Scope

## Confirmed Facts

## Assumptions

## Contradictions / Blockers

## Findings

## Options

## Recommended Plan

## Risks

## Verification Strategy

## Open Questions
```
