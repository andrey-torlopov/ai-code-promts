# Mode: plan

Use for implementation plans, migration plans and scoped analysis before code changes.

## Knowledge

Per the scope table in `../SKILL.md`; no mode-specific additions.

## Workflow

1. Verify that the requested scope exists.
2. Inspect files before planning.
3. Count relevant files and visible boundaries when the scope is filesystem-based.
4. Separate facts, assumptions, blockers and decisions.
5. Produce an implementation-ready plan with acceptance criteria.

## Stop

Write or return the plan. Do not implement.
