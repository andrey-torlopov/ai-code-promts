# Mode: research

Use for standalone research, comparisons and source-backed synthesis.

## Knowledge

Load domain knowledge only if the report depends on repository-local conventions.
For volatile external topics, verify current primary sources before writing claims.

## References

- `../references/research-source-policy.md`
- `../references/research-report-template.md`
- `../references/evidence-rules.md`

## Workflow

1. Define the research question, scope, exclusions and source criteria.
2. Identify whether the topic is volatile.
3. Use current sources for volatile claims.
4. Separate facts, source-backed findings, inference, recommendations and unknowns.
5. Save the report to the requested path, or choose a clear path under `tmp/` for short research.

## Stop

Do not invent sources, dates, versions or quotes. Do not modify project code.
