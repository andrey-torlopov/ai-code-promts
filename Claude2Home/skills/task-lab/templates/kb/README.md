# Knowledge — внешняя база знаний

Переиспользуемая база знаний проекта. Каждый файл самодостаточен: одна тема, свой срез
кода и ревизия, читается без доступа к задачам, из которых родился. Устаревшее не
архивируется, а физически удаляется — файл и строка реестра — только по явному запросу
пользователя. ID закрепляется за записью навсегда и не переиспользуется: следующий номер
выдаёт счётчик ниже, при удалении он не откатывается.

Последние выданные ID: F-00 · H-00

Формат строки: `ID` — ссылка на файл (`[F-01](player-architecture.md)`; имя файла
свободное, номер закреплён здесь); `Tags` — крупные категории через запятую (App, SDK,
Player, marketplace, …) — до изобретения нового тега посмотреть существующие; `Описание` —
одна строка о том, что внутри; `Источник / срез` — ветка/ревизия и дата, следующей строкой
в той же ячейке — `<br>Задачи: WIBE-001, WIBE-1020` — папки task-lab, из которых запись
вытащили или которые брали её в работу.

Правила пополнения: один файл — одна тема; у каждого утверждения — файл/строка и ревизия;
числа с числителем и знаменателем; ссылки внутрь чьих-либо задачных папок запрещены.
