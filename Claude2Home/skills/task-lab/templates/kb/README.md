# Knowledge — реестр фактов и гипотез

Плоская база актуального знания проекта. Один файл — одно утверждение; файл атомарен,
самодостаточен и компактен: скопированный в одиночку, он не теряет информации и не
заставляет искать записи, от которых зависел. `F-NN` — проверено с доказательством,
`H-NN` — гипотеза. Устаревшее не архивируется, а физически удаляется — файл и строка
реестра — только по явному запросу пользователя. ID никогда не переиспользуются:
следующий номер выдаёт строка-счётчик ниже, при удалении она не откатывается.
