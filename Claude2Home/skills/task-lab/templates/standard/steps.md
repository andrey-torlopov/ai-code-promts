# Шаги — история

Корневой реестр шагов. Один шаг — один запрос пользователя: план в `Steps/Step-XX.md`, результат в
`Steps/Step-XX-result.md`. Новая пара всегда встаёт **первой строкой** таблицы: последний шаг сверху.

## Текущий шаг

**Нет.** Следующий запрос пользователя создаст `Steps/Step-01.md`.

## Рекомендуемая очередность

Короткий план для заказчика: каждый пункт самодостаточен — по нему можно сказать «сделай
следующий шаг», не заглядывая в другие папки. Без внутренних ID (`Q-NN`) и без ссылок в
`Context/`. Порядок — предложение, а не обязательство; блок обновляется при закрытии
каждого шага.

1. — кандидатов пока нет; блок заполнится по мере первых наблюдений —
