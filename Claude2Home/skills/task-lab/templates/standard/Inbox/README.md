# Inbox — временные входные материалы

Эта папка может быть удалена без потери состояния задачи. Материалы здесь не являются источником
истины и могут относиться к другой ревизии предмета.

Правила:

1. Использовать материалы только для поиска кандидатов в гипотезы.
2. Перепроверять долговечные утверждения на авторитетном предмете и записывать их в `Knowledge/`.
3. Не создавать из `Knowledge/`, `Steps/`, `Results/` и `README.md` ссылок на файлы здесь.
4. Не удалять без явного разрешения пользователя, даже когда аудит зелёный: сначала аудит должен
   показать, что ни один долговечный файл отсюда не зависит.
