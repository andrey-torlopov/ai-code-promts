# Results — деливерабл

Здесь лежат самодостаточные результаты задачи. Их можно скопировать без остальной папки: они
читаются и исполняются без реестра фактов, без истории шагов и без контекста чата.

## Что здесь

| Файл | Что внутри |
|---|---|
| — | результатов пока нет |

## Правила для содержимого этой папки

1. **Никаких ссылок наружу из `Results/`** и никаких путей внутрь папки задачи.
2. **Никаких ссылок на `F-NN` и `H-NN`.** Нужный контекст дублируется текстом.
3. Каждый файл имеет аудиторию, назначение и критерий готовности.
4. Числа приводятся с числителем, знаменателем и единицами.
5. Подпапки допустимы, когда деливерабл состоит из набора однотипных единиц.
