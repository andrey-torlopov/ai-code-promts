# Восстановление сессии

Если сессия оборвалась — этот файл возвращает в работу за три минуты.

## Порядок чтения

1. `00-START-HERE.md` — задача, границы, инварианты.
2. `../steps.md` — история и указатель: есть ли `Steps/Step-XX.md` без парного
   `Step-XX-result.md`. Если нет — открытого шага нет, ждём запроса пользователя.
3. `../Knowledge/README.md` — что уже установлено и что ещё гипотеза.
4. `10-repo-and-revisions.md` — ревизии и команды.
5. `20-code-map.md` — куда идти за конкретным материалом.
6. `40-queue.md` — кандидаты на следующий шаг и вопросы на пользователе.

Всё остальное — по необходимости. Историю целиком читать не обязательно: `../steps.md` держит
вердикты, детали — в паре файлов нужного шага.
