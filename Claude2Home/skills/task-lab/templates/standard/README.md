## Устройство папки

```text
README.md      ← вы здесь: состояние и навигация
index.md       точка входа для ИИ-агента
steps.md       история шагов: свежие сверху, со ссылками на план и результат каждого
Context/       служебное для ИИ: границы, метод, карта предмета, очередь, восстановление
               сессии; скрипты расчётов — в Context/tools/
Knowledge/     реестр фактов F-NN и гипотез H-NN, по одному утверждению на файл
Steps/         пары «шаг + результат»: Step-XX.md — план по запросу, Step-XX-result.md — вердикт
Results/       самодостаточный деливерабл: читается без остальной папки
Notes/         черновые заметки и журналы наблюдений; на состояние задачи не влияет
Logs/          сырой машинный вывод: логи, трейсы, профили, выгрузки; рядом с Notes/, не внутри неё
Inbox/         входные материалы — временная папка, к удалению
```

**Как идёт работа.** Вы описываете, что нужно сделать. На этот запрос заводится `Steps/Step-XX.md` —
план с вопросом шага и критерием завершения; только после этого начинается работа. Итог уходит в
`Steps/Step-XX-result.md`, строка — первой в `steps.md`. Заранее следующие шаги не планируются и не
нумеруются: кандидаты лежат в `Context/40-queue.md`, а какой из них станет шагом — решаете вы.

**Шагом оформляется любая правка** — отчёта, реестра или кода, — даже если это одна строка: по
истории должно быть видно, как документ пришёл к текущему виду. Ваш вопрос, ответ на который
целиком помещается в переписку («что сделано», «где это лежит», «почему так»), шага не создаёт и
историю не засоряет.

Служебная точка входа агента — [`index.md`](index.md).
