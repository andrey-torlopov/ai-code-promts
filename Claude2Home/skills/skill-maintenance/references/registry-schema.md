# Registry Schema

Use this Markdown structure:

```markdown
# AI Setup Registry

> Updated: absolute date
> Root: scanned root path

## Summary

| Metric | Value |
|---|---:|
| Skills | number of skill folders |
| Skill Markdown files | number of SKILL.md files |
| Reference Markdown files | number of reference files |

## Skills

| Skill | Path | Purpose | References | Scripts | Assets |
|---|---|---|---:|---:|---:|

## Instruction Entrypoints

| File | Lines | Purpose |
|---|---:|---|

## Validation / Hooks

| File | Purpose |
|---|---|

## Changelog

| Date | Change |
|---|---|
```

All rows must be based on existing files.
