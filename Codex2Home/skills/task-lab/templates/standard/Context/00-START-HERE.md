## Инварианты работы

Каждый инвариант содержит причину; нарушение обесценивает вывод.

INV-1. **{{FILL_AUTHORITATIVE_SUBJECT_AND_REVISION}}** — иначе ссылки и выводы относятся к другой системе.
INV-2. **{{FILL_FORBIDDEN_CHANGE_OR_COMPARISON}}** — иначе проверка перестаёт отвечать на вопрос задачи.
INV-3. **Шаг заводится только по запросу пользователя, один шаг — один вердикт.** Открытым может быть ровно один шаг: `Steps/Step-XX.md` без парного результата. Заранее ничего не нумеруется — кандидаты живут в `40-queue.md`.
INV-4. **Любая правка файла по запросу — это шаг, даже на одну строку; вопрос с ответом в реплике — не шаг.** Иначе история перестаёт объяснять, как отчёт пришёл к текущему виду. Исключения: черновик в `Notes/` и запись дрейфа в `90-session-restore.md`.
INV-5. **Одно причинное изменение на один гейт** — иначе вердикт неатрибутируем.
INV-6. **Числа:** числитель / знаменатель = результат, с единицами и областью действия. Расчёт — скриптом в `Context/tools/`.
INV-7. **В `Results/` нельзя ссылаться на `F-NN` / `H-NN` и на пути этой папки** — деливерабл уезжает наружу.
