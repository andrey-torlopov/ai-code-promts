# Change Report

Use this final structure after implementation:

```text
Changed:
- <path>: <what changed>

Verification:
- <command/check>: <result>

Residual risk:
- <risk or none>

TRACE:
- Skill: implementation-from-plan
- Task folder:
- References read:
- Knowledge read:
- Patterns/policies applied:
- Verification:
- Residual risk:
```

If verification was not run, say exactly why.
