# Documentation Practices

Use these principles:

- Single source of truth: keep each fact in one place and link to it elsewhere.
- Progressive disclosure: keep entry files short and move details to references.
- Scannability: headings, tables and concise sections beat long prose.
- One document type per file when practical: tutorial, how-to, reference or explanation.
- Atomic agent skills are allowed to duplicate minimal operating rules so they can work independently.
